# PowerShell JSON 时间转换导致进程记录误判

- **类型：** Pitfall
- **日期：** 2026-10-19
- **状态：** Confirmed

## 原因

当前 PowerShell 的 `ConvertFrom-Json` 会把 ISO 时间字符串转换为 `DateTime`。若用进程启动时间的格式化字符串与该对象直接比较，同一进程也可能不匹配，导致重复启动误报端口占用、停止操作遗留运行进程。

## 处理与验证

启动记录新增字符串形式的 UTC ticks，启动与停止统一使用 `Test-LocalProcessIdentity` 比较时间刻度，并检查所属项目。兼容旧的 ISO 字符串和日期对象记录。

已验证相同进程匹配、错误时间和空进程不匹配；实际停止后 80、48080 端口均释放，重新启动成功，再次启动复用相同 PID。
